# Codex 屏幕眼睛 · 0.4 自动语音测试版

Windows 本地插件，截图程序和设置窗口都包含在插件包内，无需另装 Python 或单独安装伴侣软件。

## 首次配置

安装后在新聊天说「打开 screen-eyes 共享设置」，调用 screen_setup。选择窗口或显示器，勾选「跟随语音自动共享」。这表示同意以后在本机原生语音会话开始时共享该来源。关闭设置窗口后，后台仍等待语音；首次配置需要在开始语音前完成。

## 日常使用

打开原生语音时，后台读取新产生的本地语音开始记录，开启所选来源。你询问画面时 Codex 获取新截图；没有持续上传视频。正常结束、失败结束或桌面客户端退出时停止共享。

说「停止共享」或设置窗口点击暂停后，同一次语音不会自动重新开启；下一次新语音可以恢复。取消自动共享复选框后，不再跟随后续语音。

设置窗口不必一直打开。自动共享最长 4 小时；状态无法读取或后台心跳过期时不能取图。启动后台时已经进行中的语音不会被追溯开启，请开始下一次语音。已关闭、最小化或变化的来源需重新选择。

## 实验性限制

自动跟随依赖 Codex 用户目录 sessions 下的 realtime_item 开始/关闭记录，目前没有官方 VoiceStart/VoiceEnd Hook。此适配可能被客户端更新影响。正常事件延迟通常是轮询间隔与客户端写入延迟之和；2026-10-02 已在本机当前客户端的真实麦克风会话中验证自动开启、两次成功取图和结束后停止；自动进程回放测试也已通过。其他客户端版本仍需验证。

插件后台在 MCP 初始化或首次勾选自动共享时启动。并非 Windows 开机自启，也不保证 Codex 尚未加载此插件时已经运行。在原生语音前先完成首次配置。遇到 Codex 升级后未自动启动，可以说「打开共享设置」，重新加载后台。

本插件不会改变系统代理。原有网络页可用于保存 Codex 连接设置；本次自动升级保留已跑通的代理配置。只在用户主动保存时修改 Codex .env，变更需重新启动后台。

截图会经 Codex 发送给模型。窗口遮挡内容也可能进入截图。本地适配器只提取生命周期字段，不保存音频或转写，不把会话记录发送给其他服务。

## 分发

plugin.json 与 mcp.json 使用 Agent Plugins 格式，程序位置相对插件根目录，状态使用 Codex 的 PLUGIN_DATA。可通过本地或仓库 marketplace 分享此 Windows 插件包。官方目录有 ZIP 上传与审核流程，但标准公共 MCP 提交要求公开 HTTPS 端点；本地 MCP 无法部署时需联系 OpenAI 获取支持。当前 EXE / stdio 方案不能直接视为符合标准公共提交条件，尚未上传、送审或获批。

公开上架还需要发布者身份和实际支持/隐私/条款页面，不能把本机可安装与官方公共发布混为一谈。

Codex 屏幕眼睛

使用说明 · Windows 本地插件测试版 0.4 · 2026-10-02

选好画面 → 开始原生语音 → 询问屏幕 → 结束后自动停止

这是什么

为 Codex 原生语音提供按需截图能力。截图程序、设置窗口和工具都包含在插件包内，无需另装 Python。

开启语音会自动允许共享已选来源；当你询问画面、Codex 调用查看工具时，才获取新截图。它不是持续视频流，也不会自动操作鼠标键盘。

本机真实语音已验证自动开启、两次新截图和结束后停止。自动跟随仍属实验功能，Codex 更新可能影响兼容性。

你这台电脑：三步开始

  1. 在 Codex 新聊天中说或输入：“打开 screen-eyes 共享设置。”也可以双击桌面的“Codex 语音伴侣”快捷方式。
  2. 在“屏幕共享”页选择显示器或窗口，勾选“跟随语音自动共享”。看到“等待下一次语音开始”后，可以关闭设置窗口。
  3. 开始一个新的 Codex 原生语音聊天，说：“用 screen-eyes 看看我的屏幕，告诉我现在显示什么。”

结束语音后自动停止共享。首次配置必须在开始语音前完成；已经进行中的语音不会被追溯开启。

你这台电脑已经安装并配置好了，无需重复安装或点击“连接到 Codex”。

多个显示器

现版一次选择一个显示器或一个窗口。在下拉框选择“显示器 1”或“显示器 2”，自动模式会保存选择，下次语音使用该来源。

共享指定窗口时，窗口移到另一块显示器上，截图区域会随窗口位置移动。请保持窗口可见，不要最小化。

切换来源会暂停当前共享。若要立即继续，点击“开始共享”，此时进入手动共享，设置窗口需要保持打开。

目前不支持同时拼接全部显示器，也不会根据鼠标位置自动切换。插拔显示器或改变排列后，请刷新并重新选择。

暂停与手动共享

说“用 screen-eyes 停止共享”，或在设置中点击“暂停”。同一次语音不会自动重新开启；下一次新语音可以恢复。希望以后也不自动开启时，取消自动共享复选框。

手动模式：选择来源并点击“开始共享”，再回到 Codex 请求查看。“预览画面”可以检查范围。手动共享需要保持设置窗口打开，关闭窗口即停止。

自动模式可关闭设置窗口，后台继续等待或跟随语音。自动共享最长 4 小时；客户端退出、语音正常或失败结束、后台心跳失效等情况下会停止或禁止取图。

连接设置与代理

网络正常时不用改设置，也不必每次通过本软件启动 Codex。

  • 自动检测：读取可识别的 Windows 或环境变量代理，不固定使用 7890 等端口。
  • 直接连接：适合不需要代理的网络，或 VPN 的 TUN 模式，会清除 Codex 中残留的代理项。
  • 手动代理：填写自己软件提供的 HTTP / mixed 地址和端口，不要照搬其他人的端口。

自动检测不会持续跟踪 VPN 变化，切换网络后请重新保存。PAC 或只有 SOCKS 的入口需另行配置 HTTP / mixed 入口。

设置只作用于 Codex，不修改 Windows 系统代理。修改并保存后，需要完整退出再打开 Codex；仅调整共享来源不需要重启。

已经安装插件时，不要重复点击“连接到 Codex”，以免直接 MCP 注册覆盖插件配置。

常用说法

  • 打开设置：“打开 screen-eyes 共享设置。”
  • 查看画面：“用 screen-eyes 看看我当前屏幕。”
  • 查看变化：“重新查看共享屏幕，告诉我刚才有什么变化。”
  • 暂停：“用 screen-eyes 停止共享。”
  • 检查状态：“检查 screen-eyes 的共享状态。”

如果 Codex 只说“我再试试”，请明确要求调用 screen_look 并报告工具结果。仅口头承诺不代表已经取图。

常见问题

  • 只有听写：尝试在新聊天页面启动原生语音。插件不提供或解锁语音入口。
  • 看不到屏幕：打开设置，确认来源和自动共享；结束原来的语音，再开始新的语音。也可用手动“开始共享”检查。
  • 没有工具：确认 screen-eyes 插件已启用，在新聊天中重试。首次安装仍未加载时，可完整退出再打开 Codex。
  • 画面错了：点击“刷新窗口”并重新选择。关闭后重新打开的窗口可能需要重新选择。
  • 截图中有其他窗口：窗口共享截取屏幕上的窗口区域，遮挡内容也可能进入截图。请移开遮挡。
  • 升级后自动共享不启动：打开共享设置重新加载后台，再开始新语音。仍失败时，暂停共享并提供错误信息。
  • 关闭设置就停了：这是手动模式的行为。需要后台跟随时，勾选自动模式，从下一次新语音开始。

安装与分发状态

当前版本为 0.4.0-preview+codex.20261002033358，仅适用于 Windows 本地桌面环境。本机通过 personal 本地插件来源安装。

ZIP 是可供本地或仓库 marketplace 分发的插件包，不是双击即安装的 Windows 安装器。其他人使用时，先解压到固定目录，再让 Codex 将该目录作为本地插件加入个人 marketplace 并安装 screen-eyes；安装后配置自己的共享来源。客户端必须支持相应本地插件安装功能，命令与界面可能随版本变化。

只分享干净插件 ZIP，不要复制本机的代理 .env、状态、截图、会话或诊断目录。

截至 2026-10-02，尚未上传、送审或在官方公共市场发布。标准公共 MCP 提交流程要求公开 HTTPS 服务；本插件使用本地 EXE / stdio MCP，需先取得本地 MCP 支持，不能保证直接上传后获准上架。

个人或仓库 marketplace 分享，与官方公共市场上架是两件不同的事。

画面与数据

截图会经 Codex 发送给模型。只选择愿意共享的来源，留意截图范围内的密码、私密聊天和文件。

后台从本机 Codex 语音记录提取生命周期字段，用来判断开始与结束；本地适配器不另行保存音频或转写，也不把会话日志发送到其他服务。这不替代 Codex / OpenAI 自身的数据政策。

主文件保存在 D:\Software\codex屏幕共享。Codex 管理的缓存和插件状态仍由 Codex 保存在用户目录，不需要手工搬动。
